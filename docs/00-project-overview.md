# Express Web Platform — Project Overview

**Status:** Initial baseline  
**Repository:** `express-web-platform`  
**Production:** `https://www.express-web.express`  
**Updated:** 2026-07-29

## Purpose
Express Web is the central website, product showcase, content hub and lead-generation platform of the Express Web business. It is not treated as a static agency website, but as a modular platform that will gradually combine services, projects, blog content, newsletter communication, analytics, chatbot support, campaign landing pages and future AI-assisted products.

## Vision
The platform should demonstrate the same quality and discipline offered to clients. It must clearly explain services, build trust, generate qualified inquiries, support controlled commercialisation and remain understandable as it grows.

## Primary audiences
- micro and small businesses needing a professional website;
- companies planning online sales;
- organisations needing custom web applications;
- businesses interested in digitalisation, marketing and AI support;
- existing site owners needing maintenance, SEO, analytics or redesign.

## Known technology baseline
- Vue 3, Vite, Tailwind CSS, Vue Router and i18n;
- Laravel backend/API;
- MySQL-compatible database;
- Git and GitHub;
- Cloudways production hosting;
- Serbian and English, with German support under development.

Exact versions and topology must be verified by the first repository audit.

## Development methodology
1. Analysis.
2. Update relevant documentation.
3. Create `docs/tasks/EW-XXX.md`.
4. Prepare a precise Codex prompt.
5. Implement in a scoped branch.
6. Review code, tests and behaviour.
7. Commit and deploy through the documented process.
8. Perform production smoke tests and close the task.

## Definition of done
A task is done only when acceptance criteria are met, changes are reviewed, tests/checks are recorded, documentation is updated, secrets are absent, the commit is traceable and production verification is completed when deployed.
